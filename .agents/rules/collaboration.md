# Collaboration & Execution Rules

## Pair-Programming Protocol
1. **No Autonomous Changes:** Never make changes, edits, or create new files proactively unless explicitly commanded by the user.
2. **Strict Scope Boundary:** When the user issues a command, implement changes ONLY for that specific command. Do not add extra features, refactor unrelated code, or do speculative work.
3. **Wait for Command:** Once the commanded change is completed, stop immediately, report the status concisely, and wait for the user's next command.
