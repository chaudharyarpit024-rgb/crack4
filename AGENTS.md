# Project Rules & Collaboration Protocol

## Strict Execution Constraints
1. **Never make uncommanded changes:** Do not modify, add, or delete files on your own initiative. All changes require an explicit user command.
2. **Execute only what is commanded:** When a specific command is given, make changes strictly limited to that command—nothing more, nothing speculative.
3. **Wait for next directive:** After executing a command, stop and wait for the user's next command.
